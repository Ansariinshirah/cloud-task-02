# InfoSetu: Service Blueprint, SLOs and Cloud Cost Envelope (Task 02)

InfoSetu is a multilingual (English, Hindi, Marathi) public-service platform where citizens submit complaints and information requests and admins resolve them. Users are citizens (who see only their own requests) and administrators (who manage all requests). It depends on a Python app, a SQLite database, Elasticsearch for search, and an email/SMS service.

## Files
- PNG files : request, dependency, deployment, data and failure paths (PNG)
- slo-workbook.xlsx: SLIs, SLOs, error budgets, paging thresholds
- cost-model.xlsx: monthly cost for Lean, Balanced and Resilient scenarios
- architecture-decision-records.pdf: region, recovery, secrets, least privilege
